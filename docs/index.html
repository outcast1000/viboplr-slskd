Set up slskd

Viboplr can't speak Soulseek itself, so the Soulseek plugin drives slskd: a free, open-source Soulseek daemon that you install and run. It's a ten-minute job. slskd stays yours — its files, its settings, its process; Viboplr only talks to it over its local API.

Your API key. Generated by the Soulseek plugin and already filled into the config below; it must match the API key field in the plugin.

  1. Download

    Get slskd-<version>-win-x64.zip from the releases page and extract it somewhere it can stay, for example C:\slskd. It's a single slskd.exe plus a few files.

    Open slskd releases

  2. Run it once

    Double-click slskd.exe. A console window opens and slskd creates its settings folder at %LOCALAPPDATA%\slskd with a slskd.yml inside. Close the window (or press Ctrl+C) before the next step.

    The first start asks to allow incoming connections (port 50300). Allow it — otherwise other Soulseek users can't reach you and downloads are slow to start.

  3. Configure

    Paste %LOCALAPPDATA%\slskd\slskd.yml into the Explorer address bar, or open it from Notepad. Add the lines below (indentation matters — two spaces per level).     Start it again
    
        
    Run slskd.exe again and keep the console window open while you use Soulseek — minimising is fine.
    
        
    Or make it start hidden at every login: paste this into a PowerShell window, after changing the path on the first line to where you put slskd.exe.
    
        
    $exe = "C:\slskd\slskd.exe"   # <- your path
$lnk = "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\slskd.lnk"
$s = (New-Object -ComObject WScript.Shell).CreateShortcut($lnk)
$s.TargetPath = "powershell.exe"
$s.Arguments = "-WindowStyle Hidden -Command Start-Process -WindowStyle Hidden '$exe'"
$s.Save()
    
        
    To undo: delete slskd.lnk from that Startup folder.

  5. 
        
    Connect
    
        
    Back in Viboplr, open Soulseek in the sidebar and press Connect. Finished downloads land in %LOCALAPPDATA%\slskd\downloads; add that folder as a music source in Collections and they join your library on their own.
    
        
    slskd's own web page is at http://localhost:5030, user slskd / password slskd. You don't need it for Viboplr, but change that password in slskd.yml (web.authentication.username / password) if other people use this computer.

    Download

        Open slskd releases
      
    2. 
      
  2. 
        
    Run it once
    
        
    macOS blocks unsigned downloads, so the first start has to come from Terminal. These three commands clear the download flag, make it executable and start it. slskd creates ~/.local/share/slskd/slskd.yml. Press Ctrl+C to stop it.
    
        
    xattr -dr com.apple.quarantine ~/slskd
chmod +x ~/slskd/slskd
~/slskd/slskd
    
        
    The first start asks to allow incoming connections (port 50300). Allow it — otherwise other Soulseek users can't reach you and downloads are slow to start.
    
      
    3. 
      
  3. 
        
    Configure
    
        
    open -e ~/.local/share/slskd/slskd.yml opens the file in TextEdit. Add the lines below (indentation matters — two spaces per level). Replace the two Soulseek placeholders with your own account; the key is already yours. If the file already has an uncommented soulseek: or web: section, add the lines inside it instead of repeating the heading.
    
        
    
      
    4. 
      
  4. 
        
    Start it again
    
        
    ~/slskd/slskd in Terminal starts it; leave that window open.
    
        
    Or start it in the background at every login with a launch agent — paste the whole block into Terminal once.
    
        
    cat > ~/Library/LaunchAgents/com.slskd.plist <<EOF
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>com.slskd</string>
  <key>ProgramArguments</key><array><string>${HOME}/slskd/slskd</string></array>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
  <key>StandardOutPath</key><string>${HOME}/.local/share/slskd/launchd.log</string>
  <key>StandardErrorPath</key><string>${HOME}/.local/share/slskd/launchd.log</string>
</dict></plist>
EOF
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.slskd.plist
    
        
    To undo: launchctl bootout gui/$(id -u)/com.slskd and delete the plist.

    Start the container
    
        
    One command, on the machine that will run it. slskd's settings and downloads are kept in ~/slskd on the host.
    
        
    mkdir -p ~/slskd
docker run -d --name slskd --restart unless-stopped \
  -p 5030:5030 -p 50300:50300 \
  -v ~/slskd:/app \
  --user $(id -u):$(id -g) \
  slskd/slskd:latest

  2. 
        
    Configure
    
        
    The first start creates ~/slskd/slskd.yml. Add the lines below (indentation matters — two spaces per level). Replace the two Soulseek placeholders with your own account; the key is already yours. If the file already has an uncommented soulseek: or web: section, add the lines inside it instead of repeating the heading. Then docker restart slskd.

  3. 
        
    Connect
    
        
    Back in Viboplr, open Soulseek in the sidebar. If Docker runs on this same computer, press Connect; otherwise type the machine's address (for example http://nas.local:5030) into the Connection section. Downloads land in ~/slskd/downloads on that machine — add the folder (or its network share) as a music source in Collections.
    
        
    slskd's own web page is on port 5030, user slskd / password slskd. Change that password in slskd.yml if the machine is reachable by others.
